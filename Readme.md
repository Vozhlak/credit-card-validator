# Credit Card Validator

Валидатор номеров банковских карт, реализующий проверку формата, алгоритм Луна и определение банка-эмитента по BIN (Bank Identification Number).

## 📋 Описание проекта

Это консольное приложение на Go, которое:
- Принимает номер кредитной карты от пользователя (с поддержкой пробелов и тире)
- Проверяет, что номер содержит от 13 до 19 цифр
- Валидирует номер с помощью алгоритма Луна
- Извлекает первые 6 цифр (BIN) и определяет банк-эмитент по заранее загруженному списку банков

Проект демонстрирует идиоматичный Go-код, обработку ошибок, работу с файлами и строгую валидацию пользовательского ввода.

## 🛠 Основные функции

- ✅ **Гибкий ввод**: поддержка номеров с пробелами и тире (например, `4000 0000 0000 0002`)
- ✅ **Проверка длины**: валидные номера содержат от 13 до 19 цифр
- ✅ **Алгоритм Луна**: проверка контрольной суммы для обнаружения ошибок ввода
- ✅ **Определение банка**: сопоставление BIN с диапазонами банков из файла `banks.txt`
- ✅ **Безопасность**: никакие данные не отправляются в сеть — вся обработка локальная

## 🚀 Установка и запуск

### Требования
- Go 1.22 или выше

### Инструкции

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Vozhlak/credit-card-validator.git
   ```
   
2. Перейдите в директорию проекта
   ```bash
   cd credit-card-validator
   ```
   
3. Запустите проект
   ```bash
   go run .
   ```
   
4. Следуйте инструкциям в консоли. Для завершения программы просто нажмите Enter без ввода.

## 🎮 Примеры использования
Пример 1: Валидный номер с пробелами
```text
Введите номер карты (или нажмите Enter для выхода из программы): 4000 0000 0000 0002
✅ Номер карты валиден
🏦 Банк: Lunar Bank
```
Пример 2: Невалидный номер (не проходит Луна)
```text
Введите номер карты (или нажмите Enter для выхода из программы): 1234 5678 9012 3456
❌ Невалидный номер карты (не проходит проверку Луна)
```
Пример 3: Номер с неизвестным эмитентом
```text
Введите номер карты (или нажмите Enter для выхода из программы): 4111 1111 1111 1111
✅ Номер карты валиден
Эмитент не определён
```
Пример 4: Некорректная длина
```text
Введите номер карты (или нажмите Enter для выхода из программы): 12345
❌ Неверная длина номера: 5 цифр (должно быть 13–19)
```
